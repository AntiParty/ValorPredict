Questions

Who can use it?

Any Valorant streamer on Windows whose Twitch channel can run Channel Points Predictions. Twitch only allows predictions on Affiliate and Partner channels.

Can it get my account banned?

ValorPredict does not read or write game memory, inject code, capture your screen or touch Vanguard. It only reads the local data the Riot Client already provides and Riot's match-state services, and it never sends anything to the game. The full list of what it reads is in the README, with links to the code for each step.

What does it cost?

Nothing. ValorPredict is free and open source under the MIT license.

When can I download it?
